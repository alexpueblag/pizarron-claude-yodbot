Activar el guardado de Ajedrex

El código y la hoja están preparados. Falta instalar y desplegar Apps Script con tu cuenta de Google.

Descargar el código completo
  1. Abre tu Sheet de Ajedrex → Extensiones → Apps Script.
  2. Pega el contenido de Code.gs, guarda y ejecuta instalarAjedrex_. Autoriza el acceso de Google.
  3. Implementar → Nueva implementación → Aplicación web. Ejecutar como tú, acceso Cualquier persona. La hoja permanece privada; el servidor comprueba cada acceso.
  4. Copia la URL /exec y pásala en el chat para terminar de conectar y comprobar el guardado.

La configuración inicial del editor se realiza mejor desde una computadora.
